# networkwalks-B082-week1-Cybersecurity-lab-setup
networkwalks-B082-week1-Cybersecurity-lab-setup guide of my work
PHASE 1
Step 1. Download & install 7-zip: https://7-zip.org/download.html 
Step 2. Download & install Virtualbox on your laptop/PC: https://virtualbox.org/wiki/Downloads 
Step 3. Configure the network settings on your Virtualbox (create NATNetwork in 10.0.0.0/24) 
Step 4. Download & import Kali Linux Virtual Machine in your Virtualbox: https://kali.org/get-kali  Step 5. Setup the IP configuration of Kali Linux Step 6. Take snapshot of the VM.

Install and configure virtualBox.
Install or import Kali linux as a virtual machine.

Configure network connectivity for kali linux.
